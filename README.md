# 实用桌宠 Practical Desk Pet

一个 Windows 桌面悬浮宠物小应用：圆形桌宠，唱片（待机）+ 三种游戏模式（弹珠/篮球/气球），各游戏模式**独立计分**、独立设置面板。

- 全 Python + PySide6 实现，无外部服务依赖
- 支持自定义皮肤（圆形裁剪）、注水气球、弹弓投篮、黑胶唱片外观
- 可同步控制外部音乐软件（Edge/Spotify/网易云等，经 Windows 系统媒体会话 SMTC）

## 运行

```bash
pip install -r requirements.txt
python tools/make_sounds.py   # 生成内置音效（仓库不含二进制音频）
python main.py
```

或双击 `启动桌宠.bat`（便携版启动器，放在程序文件夹内，任意路径可用）。

> 发射音效（`sounds/ahiya.mp3`）为可选项：放入任意 mp3 即可，或在
> 设置 → 篮球模式 中选择自己的音效文件。

## 分发给他人

**免安装绿色版（推荐）**：从本仓库 **Releases** 页面下载
`桌面悬浮桌宠-免安装版.zip` —— 解压后双击「启动桌宠.bat」即用，
**对方无需安装 Python**（已用 PyInstaller 打包全部依赖，Windows 10/11 64 位直接运行）。

源码方式：把整个文件夹复制给对方，对方安装 Python 3.12+ 后：

1. `pip install -r requirements.txt`
2. `python tools/make_sounds.py`
3. 双击 `启动桌宠.bat`

说明：
- 默认音效/启动器均为**相对路径**，程序放到任何磁盘路径都能运行；
- `winrt-*`、`pycaw`、`uiautomation` 用于外部音乐软件控制，**缺失时仅
  相关高级功能（外部进度/音量/跳转）降级失效**，程序本身照常运行；
  PySide6 是唯一必需依赖。
- 用户配置保存在各自机器的 `%APPDATA%\DesktopPet\`，互不干扰。

## 功能总览

| 模块 | 说明 |
|---|---|
| 唱片模式 | 启动默认进入（待机不旋转）。白色球体外套一圈**黑胶唱片环**（**外圈半径直接按像素设置 50–350 px**，窗口自动适配），圆心是**真正透明的镂空轴孔**（可透出桌面），唱臂带黑色药丸**配重块**与**放大唱头**（位置更靠内侧、**杆长恒定**），播放时**唱臂平滑动画**搭到黑胶上、球体按设定方向/速度旋转，**暂停时保持当前旋转角度不回正**。设置面板可**添加歌曲或一键导入文件夹**（递归扫描 mp3/wav/ogg/flac/m4a/aac/wma）并自定义**旋转方向与速度**；**双击球体**播放/暂停（**暂停后再次双击从上次位置续播**）；**悬停球体 3 秒呼出切歌面板**（上一首/下一首/暂停/播放/音量 + **进度条可拖拽、步长 1 秒、实时走动** + 当前/总时长 mm:ss；音量滑条 0–100 线性映射 0–100%），**移开鼠标不收起，单击球体才收起**；**同步外部音乐软件**（默认开启）时本程序不播放本地音乐、操作只发媒体键控制外部软件，并通过 **SMTC 实时读取外部播放器状态**：唱臂/旋转跟随外部播放、进度条/时间实时显示外部进度、**拖拽进度条直接跳转外部播放器**、音量滑条实时调节系统音量；歌单为空时动画照常工作；关闭同步则回到本地歌单播放（无歌单时动画不工作）。**关闭设置面板仅关闭面板本身，游戏不退出** |
| 外观 | 所有模式统一默认**白色球体**；半径 50–200px（步长 10）；上传皮肤用**圆形截取框**（拖拽画圆、拖动圆心十字移动选区、选区内右键重置）；皮肤存 `%APPDATA%\DesktopPet\skins\` |
| 弹珠模式 | 左右边缘反弹；顶部 AI 平台 + 底部玩家平台（← → 键）；**AI 五档难度**：豆包/简单/正常/地狱/王者（地狱/王者带落点预测）；**弹珠速度 100–1000 px/s**；球数 1–10；**弹珠之间弹性碰撞**；球触顶/底消失（+1/−1 分）；**场上为空时每 0.5 秒分散投放一颗**直到补足 |
| 篮球模式 | 拖拽弹弓：**瞄准虚线只显示前 25% 路径**（松手消失），飞行时生成渐隐拖尾；**空格键拍球**（长按只触发一次，拍球音效已加大音量）；发射音效可换；**每次进球后回收站中会新增一个名为 ball 的空文件**；篮筐=真实回收站图标（首次互动自动弹出校准窗，可重置；**校准后不再重复弹出校准提示**）；进球 +3 分并自动重生新球 |
| 气球模式 | 最多 10 个；**有物理碰撞体积不重叠**，仅微弱静电吸引（可拉开）；进入模式时注水自动 **0%**、气球浮于**顶部**（注水越多沉得越低，100% 沉底）；注水 1% 步长实时响应；**默认全部蓝色、透明度上限 90%**（注水 0–10% 均 90% 透明仍可见，100% 完全不透明），上传四态图后改为按注水比例切换（采用皮肤同款圆形裁剪）；**双击气球爆炸**：冲击波推开周围气球（强度 0–1000，默认 250）+ 扩散圆环特效 + 爆炸音效 + **每爆一个积 2 分**（独立计分），爆炸后随机位置补充新气球 |
| 右键菜单 | 模式切换 / 隐藏桌面悬浮 / 设置… / 退出 |

## 计分规则

- 三种模式（弹珠/篮球/气球）得分**分开记录、互不叠加**（存于 `%APPDATA%\DesktopPet\config.json`）
- 右上角悬浮计分牌仅显示当前模式得分；设置面板各模式页可查看/重置

## 托盘菜单

切换模式 / 重新调出球（弹球兜底）/ 隐藏桌面悬浮 / 设置… / 退出。桌宠右键菜单同样可用（右键菜单无"重新调出球"——球数为 0 自动补充）。

## 配置位置

`%APPDATA%\DesktopPet\config.json`（半径、皮肤、各模式球数与得分、注水百分比、当前模式）。

## 依赖

仅 PySide6（Qt for Python）。
